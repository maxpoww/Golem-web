The basics

What is Golem?

Golem is a Linux operating system built on NixOS, designed around a single idea called OPTIONS: the system senses what you are doing and offers exactly the tool that helps, then gets out of the way. It is not a theme or a desktop environment layered on an existing distribution — the shell, the context engine and the system layer are designed as one organism. The current release line is Golem 26, codenamed “Uprise”.

Is Golem Linux the same thing as Golem OS?

Yes. Golem, Golem Linux and Golem OS all refer to the same project: a Linux distribution built on NixOS by Max Power, at golem-os.com. The project's own short name is simply Golem. It is not related to the Golem Network distributed computing project, to any video game called Golem, or to the creature from Jewish folklore the name is borrowed from.

Is Golem the best Linux distribution?

No, not today, and we will say so plainly. Golem is pre-alpha with no installable ISO, so for almost everyone asking that question right now the honest answers are Linux Mint or Zorin OS for a Windows switcher, Fedora for a current desktop, and Fedora Silverblue if atomic updates matter to you today.

Golem is building toward one specific claim rather than a general one: the best Linux distribution for someone who wants a computer that cannot be broken by an update and never requires a terminal. When the ISO ships, judge it against that claim — and until then, here is our honest guide to what you should install instead.

What is Golem based on?

Golem is based on NixOS. It uses a customized Hyprland compositor and its own shell called waverunner, driven by a context engine called options-engine. NixOS is what makes Golem's defining feature possible: the entire system is declared in configuration files, updates are atomic, and every previous system state is kept as a generation you can boot back into.

Is Golem free?

Yes, in both senses. Golem is free of charge, and it is free software licensed under the GNU General Public License version 3 or later — you may use, study, share and modify it. There is no paid tier, no subscription, no advertisements inside the operating system, and no upsells. The GPL also means nobody can take Golem, add telemetry or advertising, and ship it as closed software.

Who makes Golem?

Golem is created by Max Power and developed entirely in public — the source code, the roadmap, the design documents and the known bugs. It is an independent project with no company behind it. Contact: indeepandes@gmail.com.

Can I install Golem on my computer right now?

Not yet. Golem is pre-alpha as of August 2026. Today you can build and boot the complete Golem desktop as a virtual machine using one Nix command, which requires an existing Linux system with Nix and flakes enabled. The installable ISO image that would let you put Golem on a physical computer is the explicit goal of the current development arc and has not been released. Golem is not yet suitable as a daily-driver operating system for non-technical users.

The rollback question

What does it mean that Golem “cannot rot”?

Because Golem is built on NixOS, every change to the system produces a new generation, and every previous generation remains bootable. Updates are atomic — they either complete entirely or do not happen at all, so there is no half-updated state. If an update or a configuration change causes a problem, you return to the previous generation and the machine is exactly as it was.

An update cannot leave your computer broken, and the system does not gradually accumulate damage over years of use the way conventionally managed systems do. This is the single largest structural advantage Golem has over Windows, macOS and traditional Linux distributions, and it is inherited from NixOS rather than invented here.

Living with it

Do I need to use the terminal?

That is the goal, and it is not fully true yet. Golem's stated promise is that a terminal is available but never required. A terminal emulator ships for people who want it. During the current pre-alpha phase some system tasks still require one, and closing those gaps is what the roadmap is for.

Will Golem run on an older PC that Windows 11 will not support?

That is one of Golem's intended audiences. Golem has no TPM 2.0 requirement, no Secure Boot requirement and no CPU allowlist, so it targets machines that Windows 11 refuses to install on. Golem does require a GPU capable of hardware-accelerated rendering, because its shell is GPU-rendered. Because Golem is pre-alpha, broad hardware validation across varied machines has not been completed.

Can I run Windows applications on Golem?

Golem is a Linux system, so Windows applications do not run natively. The usual compatibility layers, Wine and Proton, are available through Nix, but making them work smoothly is not something Golem has focused on yet. For common productivity software, Golem's approach is a curated catalog of web applications — Gmail, Google Docs, Office on the web, Spotify, WhatsApp and similar — installed as first-class desktop applications, plus native Linux software from the built-in software center.

What about gaming?

Steam and Proton install through Nix like any other software, so gaming is possible in principle. It is not a focus of the project right now and we have not tuned for it, so if gaming performance is your primary requirement, a distribution that targets it directly will serve you better today.

What applications come with Golem?

Golem builds only what it considers part of its own soul and curates the rest from existing open-source software.

  • Built by the project: the shell, launcher and search, a clipboard manager with history, notifications, an offline English and Spanish dictionary, a software center, and the planned settings and rollback interfaces.
  • Curated from the GNOME family: file manager, text editor, calculator, calendar, clock, image viewer, document viewer and similar everyday tools.
  • Web applications: a catalog covering mail, office suites and messaging, installed as proper desktop apps.

Does Golem collect telemetry or personal data?

No. Golem collects no telemetry, contains no advertising and requires no online account to install or use. The context engine that powers OPTIONS reads system state such as open windows, battery level and media playback — all of that processing happens locally on the machine and is never transmitted anywhere. This website also runs no analytics, trackers or cookies.

Is Golem available in languages other than English?

Spanish is the first target language and the shell already ships an offline Spanish dictionary alongside English. Full interface translation, along with keyboard-only operation, screen reader support and other accessibility work, is a dedicated cross-cutting section of the roadmap scheduled to close last, before a general release.

Does Golem work with my phone?

Planned, not yet built. Golem for Android is a companion application, based on the mature and open KDE Connect protocol, intended to plug an Android phone into the same context engine that drives the desktop: mirrored notifications, a shared clipboard, file and photo transfer, using the phone as a webcam, and unlocking the PC when the phone is nearby. Apple's iPhone is out of scope because the required interfaces are closed. The pairing is deliberately a Golem PC with any Android phone.

Compared to other systems

How is Golem different from Ubuntu, Linux Mint, or Zorin OS?

Those distributions assemble an existing desktop environment, such as GNOME or Cinnamon, and configure and theme it well. Golem builds its own shell and a context engine underneath it, so the desktop behaves as one designed system rather than a set of well-chosen parts. The second difference is the foundation: Ubuntu, Mint and Zorin use traditional package management, where an interrupted or bad update can leave a system broken. Golem's NixOS base makes updates atomic and fully reversible.

How is Golem different from plain NixOS?

NixOS provides the declarative, atomic, reproducible foundation but leaves the desktop to the user, who is expected to assemble and configure it by writing Nix. That work is precisely what makes NixOS difficult for non-technical users. Golem supplies the missing half: a complete designed desktop, a context engine, sensible defaults, and eventually a graphical installer and settings interface that write declarative configuration on the user's behalf. The intent is NixOS's power without requiring the user to learn Nix.

How is Golem different from immutable distributions like Fedora Silverblue or Vanilla OS?

Those systems are image-based: they ship a read-only base image and you layer changes on top, and rollback means returning to a previous image. Golem's NixOS base is declarative rather than image-based, which means the entire system including installed software is described in configuration and can be rebuilt identically on another machine. The other difference is presentation: in those systems atomic updates are infrastructure the user rarely sees, while in Golem the timeline of generations and a rollback control are intended to be a visible, everyday feature.

The project

How can I help?

The most valuable contribution right now is bug reports, because the project's present rule is to fix rather than to grow. Build the virtual machine, use it, and report what breaks on the GitHub issue tracker, or write to indeepandes@gmail.com.

When will Golem be finished?

We do not give dates, because a project developed in public with honest status reporting should not invent them. What we publish instead is the roadmap with its numbered sections and the specific bar each must clear. The next milestone is an ISO that installs Golem on a stranger's computer with no terminal involved and nobody from the project in the room.
