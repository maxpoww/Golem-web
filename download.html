We tell you exactly where we are: Golem is pre-alpha. Today you can build and boot the complete Golem desktop as a virtual machine with one command. The ISO you can put on a USB stick is what Arc 1 of our roadmap exists to deliver.

Honesty first. If you want a finished, polished OS for your main machine today, we are not there yet — and we won't pretend otherwise. If you want to watch an operating system grow up in the open, welcome.

The VM — available now

Every input of the Golem flake is pinned to GitHub: any machine with Nix (flakes enabled) can build the exact same Golem PC we use ourselves. Two commands, and you're inside the full stack — the waverunner dock and launcher, the OPTIONS surfaces, notifications, the workspace overview:

# any Linux with Nix + flakes:
git clone https://github.com/maxpoww/Golem
cd Golem
nixos-rebuild build-vm --flake .#golem-vm
./result/bin/run-Golem-vm

The VM boots straight into the Golem session. It is the distribution's proving ground — what works there is what the ISO will ship.

No Nix? Install it first from nixos.org/download and enable flakes. Yes, this step is exactly the kind of friction Golem exists to eliminate — that is why the ISO is the whole point of Arc 1.

The ISO — the Arc 1 exit

Our bar for shipping it: a USB stick, another computer, a guided install — no terminal, and none of us in the room. Disk, user, wi-fi, done. Until an installation passes that test on hardware we don't own, there is no download button here.

What you'll find, what you won't

  • You'll find: the living shell — dock, launcher/search, clipboard with history, notifications, the offline EN/ES dictionary, share cards, the battery ladder, the webapp catalog, atomic NixOS ground with full rollback.
  • You won't find (yet): a graphical installer, a settings app, wi-fi/bluetooth/audio as OPTIONS surfaces (curated stopgap tools cover them), the Android companion, accessibility hardening. It's all on the public roadmap.
