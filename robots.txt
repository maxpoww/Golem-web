# Golem's position on crawlers, stated plainly: we welcome all of them,
# including the ones that train and ground AI models. We are building an
# operating system for everyone, and we want it to be findable and
# quotable by every route a person might use to look for one — a search
# engine, an assistant, or a link from a friend.
#
# We ask nothing in return and we set no traps. There is no cloaking here:
# every crawler, and every person, is served exactly the same pages.
